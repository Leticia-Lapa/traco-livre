# Traço Livre

Essa é uma **reformulação pessoal** de um web app que desenvolvi originalmente em equipe como projeto de TCC.

A proposta do projeto é criar um espaço para **artistas independentes compartilharem seus trabalhos, conhecerem diferentes estilos, trocarem experiências e encontrarem pessoas para colaborar em novos projetos.**

Depois de finalizar o TCC, decidi revisitar o projeto por conta própria, desta vez com a liberdade de repensar suas ideias e experimentar novas soluções. Esta versão funciona como um **projeto de estudo e hobby**, principalmente como uma forma de colocar em prática os conhecimentos que estou adquirindo na faculdade.

Ao longo da reformulação, estou explorando conceitos de **desenvolvimento web, UI/UX, identidade visual, organização de interfaces e estruturação de funcionalidades**, buscando transformar o que estou aprendendo em melhorias concretas para o projeto.

A ideia não é apenas reproduzir o projeto original, mas **reimaginar o Traço Livre enquanto continuo aprendendo e desenvolvendo minhas habilidades.**
